# ChurnGuard AI Backend — Build and Validation Report

Validated on **12 October 2026** using Python 3.13.5 in the available build environment.

## Real dataset training

- Source file: Kaggle Telco Customer Churn CSV supplied for this build.
- Validated dimensions: **7,043 rows × 21 columns**.
- Missing `TotalCharges` values identified: 11; for zero-tenure rows these were handled as zero charges, as explained in the README.
- Candidate models compared: Logistic Regression, Decision Tree, Random Forest, Gradient Boosting.
- Selection criterion: mean stratified cross-validation F1 for the churn class on the training split.
- Selected model: **Logistic Regression**.
- Train/holdout sizes: 5,634 / 1,409 records.

| Holdout metric | Value |
|---|---:|
| Accuracy | 0.7381 |
| Precision (churn class) | 0.5043 |
| Recall (churn class) | 0.7834 |
| F1 (churn class) | 0.6136 |
| ROC-AUC | 0.8416 |

These values describe one reproducible stratified holdout split of a static historical dataset. They are not a guarantee of future model performance.

## Packaging decisions and limitations

- The ZIP includes the source code, tests, documentation, environment template and the successfully trained model/evaluation artifacts.
- The raw Kaggle CSV is **not** included because its redistribution permission was not verified. Download it separately with `uv run python -m scripts.download_dataset`, or set `LOCAL_DATASET_PATH` to your own copy.
- If the dataset is absent, the backend starts in a clear degraded state; dataset/analytics routes return an explicit unavailable error rather than fake data. The included model artifacts remain available for inference.
- The local explainability method is single-feature baseline perturbation, not SHAP. The API documents its probability-difference scale and causal limitations.

## uv package management

- `pyproject.toml` declares runtime dependencies and the `dev` dependency group.
- `uv.lock` is generated by the first `uv sync` run; it could not be generated during packaging because the build environment could not resolve PyPI DNS. Consequently, a full dependency installation via uv could not be verified in this build environment.
- `.python-version` selects Python 3.13.
- Recommended setup: `uv python install 3.13`, `uv sync`, then invoke project commands with `uv run`.
